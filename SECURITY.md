# Security

Lonca runs coding agents with wide permissions on your machine and guards what they may do (merges, pushes, PR text).
A way around those guards is a security bug.

**Report privately** with GitHub's [private vulnerability reporting](https://github.com/selimdizer/lonca/security/advisories/new)
(the *Security* tab → *Report a vulnerability*). Please don't open a public issue for it.

Include what you ran, what the agent could do that it should not, and the Lonca commit. You'll get an answer within a week.
Only the latest `main` is supported.
